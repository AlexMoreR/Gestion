## Reglas de negocio

- `nombre_ficha_a_usuario`: al crear o editar una ficha de Equipo con usuario unido, el "Nombre completo" también se guarda como nombre del usuario (`User.name`), en la misma transacción. Así el nombre nuevo sale en ventas, cotizaciones, asistencia, nómina, comisiones y el MCP. Solo cambia el nombre; nunca correo, contraseña, rol ni módulos.
