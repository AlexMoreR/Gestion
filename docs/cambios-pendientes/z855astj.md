## Reglas de negocio

- `cuenta_aportes_del_dueno`: el tipo de cuenta `OWNER` ("Aporte del dueño") existe para registrar la plata que pone el dueño. No es plata del negocio: no sale en Configuración → Cuentas, Balances, "Dinero hoy", Nómina ni en el MCP `saldos_de_cuentas`, y no se ofrece al crear una cuenta. Parte 1 de 4: todavía no se crea ninguna cuenta de este tipo.
